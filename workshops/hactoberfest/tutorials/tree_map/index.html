What you’ll make

A pannable, zoomable campus map with green tree symbols and popups containing botanical names, tree IDs, campus locations, and photos from the CSV’s photolink field. Your final addition: a blue campus point with a description.

Workshop minutes 13–18 · About 5 minutes

1 Open the starter.

  1. Download the starter ZIP and extract it. Open the extracted campus-tree-map folder in your editor.
  2. In a terminal, change into that folder. Start a local server using one of the commands below.
  3. Open http://localhost:8000/workshops/hactoberfest/tutorials/tree_map/starter/ in your browser.
  4. Open workshops/hactoberfest/tutorials/tree_map/starter/app.js in your editor. Keep this tutorial beside it.
Terminal · Windows with Python installed 
py -m http.server 8000
Terminal · macOS / Linux with Python 3 installed 
python3 -m http.server 8000

An editor’s static server, such as VS Code Live Server, also works. Serve the extracted root folder and open the same starter path on its port. This website has no build or package installation step.

Checkpoint

You see only the shared target-map caption and a pannable, zoomable basemap. The starter has no trees or blue point yet; you will add them below. If you open the HTML with file:// , the browser may block the CSV request: use a local server.

Optional · Use the GitHub repository instead

Open the source repository and choose Code → Download ZIP, or clone it using Git. Run the local server from the repository root. The bundled starter ZIP works independently of whether the newest workshop changes have been pushed to GitHub.

Local setup blocked? Keep following along.

Open the completed map on this site as the hosted fallback. Read the completed JavaScript alongside the steps. The SDK and basemap still require internet access.

3 Read the coordinates.

Open datasets/tree_locations.csv . Each row is a tree record. The file contains 2,131 records , with no missing coordinate values. Its coordinate columns are exactly Latitude and Longitude , including capitals.

[-120.425, 37.364] puts the view near UC Merced. Reversing those values sends it somewhere else or makes the coordinate invalid.

Optional · Coordinate-system and attribute notes

The accompanying export metadata records CalculateGeometryAttributes computing Longitude POINT_X and Latitude POINT_Y in WGS 84 (EPSG:4326), decimal degrees . Those are the columns used by CSVLayer. An older State Plane California III / feet reference (EPSG:2227) in the metadata describes the source geometry, not these exported coordinate values.

Latitude ranges from 37.35994339 to 37.36805725; longitude from -120.43215179 to -120.41806030. The photo URL is in photolink. There are 2,106 HTTPS photo URLs and 25 whitespace-only values. Other columns are point_id , source_glo , featuretyp , species_id , status , and F_ . No status-code dictionary is included, so we do not interpret those codes or filter the records by status. The workshop data is a supplied snapshot, not a claim about the current inventory.

Workshop minutes 22–25 · About 3 minutes

4 Load the trees.

Replace the TODO 2 comment in starter/app.js with this block. The URL is relative to the starter page; the CSV stays in the sibling datasets folder.

app.js · Replace TODO 2 
// Load the CSV using its actual coordinate field names.
const trees = new CSVLayer({
  url: "../datasets/tree_locations.csv",
  latitudeField: "Latitude",
  longitudeField: "Longitude",
  title: "UC Merced trees"
});
map.add(trees);
Checkpoint

Save and refresh. Tree points now appear over campus with the SDK’s default symbols. Their styling and popup details come next.

A file URL and a service endpoint

Our CSV URL returns a table. CSVLayer reads its coordinates and creates the points in your browser. A service endpoint accepts API requests; a feature service layer ending in /FeatureServer/0 can support queries, filtering, and other server operations.

For a real endpoint in this project, inspect the public topographic MapServer metadata . This tiled map service supplies the basemap, not the tree attributes.

Read more: Official CSVLayer sample · CSVLayer reference . A CSV on another domain must allow CORS; our same-origin file avoids that extra setup.

Student addition: replace TODO 4 with the entire popup block below. The title uses {botanical}, the field table shows attributes, and custom content displays the image stored in photolink.

app.js · Replace TODO 4
// Show tree attributes and the image URL stored in photolink.
trees.popupTemplate = {
  title: "{botanical}",
  outFields: ["*"],
  content: [
    {
      type: "fields",
      fieldInfos: [
        { fieldName: "tree_id", label: "Tree ID" },
        { fieldName: "location", label: "Campus location" },
        { fieldName: "area", label: "Area / planting context" },
        { fieldName: "num_of_tru", label: "Number of trunks" }
      ]
    },
    {
      type: "custom",
      outFields: ["photolink", "botanical", "tree_id"],
      creator: function (event) {
        const attributes = event.graphic.attributes;
        const url = String(attributes.photolink || "").trim();
        const unavailable = document.createElement("p");
        unavailable.textContent = "Tree photo unavailable.";

        // Blank or non-HTTP URLs get a readable fallback.
        if (!/^https?:\/\//i.test(url)) return unavailable;

        const image = document.createElement("img");
        image.className = "tree-photo";
        image.alt = `Tree ${attributes.tree_id}: ${attributes.botanical}`;
        image.addEventListener("error", function () {
          image.replaceWith(unavailable);
        });
        image.src = url;
        return image;
      }
    }
  ]
};
How the photo and fallback work

outFields makes the attributes available to the popup. The photo callback reads event.graphic.attributes.photolink and trims whitespace. It creates an image with a descriptive alt text, rather than inserting data as HTML. Only HTTP or HTTPS URLs are accepted. Blank or invalid values immediately show “Tree photo unavailable.”; an image-load error replaces the image with the same message. The attribute table remains visible in every case.

The #viewDiv .tree-photo rule is already in both HTML files: images fit the popup’s width and are at most 240 pixels tall, with their aspect ratio preserved. Photo hosts need to be reachable over the network; no photos are bundled or invented.

Checkpoint

Save and refresh. Trees are green circles with white outlines. Click one: the popup shows its botanical name, tree ID, campus location, planting context, number of trunks, and its photo when available. A missing or broken photo shows “Tree photo unavailable.” while keeping the attributes readable.

Reference: SimpleRenderer · PopupTemplate · CustomContent.

6 Add your campus point.

This is the required student exercise. Choose a campus location and explain what it is, why it matters, or when someone should visit.

  1. Replace TODO 5 with the example below.
  2. Start with the supplied approximate campus coordinates, then choose another point from the tree CSV as a nearby reference. Copy its Longitude and Latitude values into the named properties. Give your place an accurate description; avoid claiming a precise building entrance without checking its position.
  3. Write your own title and descriptive popup. Use plain text in your code.
  4. Save, refresh, and click the blue diamond to check your work.
app.js · Replace TODO 5, then personalize it 
// Add an example campus point. Replace it with your own place.
const campusPoint = new Graphic({
  geometry: {
    type: "point",
    longitude: -120.4241,
    latitude: 37.3653
  },
  symbol: {
    type: "simple-marker",
    style: "diamond",
    color: "#245bd6",
    size: 16,
    outline: { color: "white", width: 2 }

    title: "My campus meeting spot",
    content: "An example meeting point near the campus core. " +
      "Replace this with your place and explain why someone should visit."
  }
});
view.graphics.add(campusPoint);
Your finish line

Your map shows trees with attributes and photo popups, plus a distinct blue diamond for your campus point. Clicking your point opens a popup with your own location name and a useful description. Explain to a neighbor which code controls the position, symbol, and popup.

Optional · Change a symbol, basemap, or geometry
  • Symbol: try a different tree color or change size: 7 to size: 10 .
  • Basemap: change basemap: "topo" to basemap: "satellite" . Both use public Esri raster services in this SDK version.
  • Geometry: try adding a polyline for a walking route or a polygon for an outdoor gathering area. These need multiple coordinate pairs; see the Graphic reference .

Help, access & next steps

Keep your map moving.

I see a blank map, or the trees never load.
  • Use http://localhost instead of opening an HTML file directly.
  • Check internet access to js.arcgis.com and services.arcgisonline.com . A school network or content blocker may block them.
  • Keep datasets beside starter , and preserve the filename and capitalized coordinate fields.
  • Put snippets inside the starter’s require callback in TODO order. Check your browser’s developer console for a missing comma, brace, or variable.
  • If port 8000 is occupied, use py -m http.server 8001 (or python3 ) and open port 8001 instead.
Do I need credentials? What services are used?

No credentials are required for the supplied example. It uses the pinned ArcGIS Maps SDK for JavaScript 4.34 CDN, the local CSV, and public Esri raster services: World Topographic Map and World Imagery . Keep the SDK’s Esri and data-provider attribution visible.

These are distinct from authenticated ArcGIS location services. Switching to a basemap style such as arcgis/topographic , a private layer, or another secured service may require an ArcGIS account, an API key, or OAuth and appropriate privileges. Follow that service’s access requirements; never put account passwords in your code. Service access and network availability can change.

Can I follow along without setting up a local server?

Open the completed map using the links above to explore the trees in your browser. Read its JavaScript beside the tutorial to follow each step. To save and run your own code changes, download the starter and serve it locally when you are ready.

The tree attributes load, but the photo does not.

Some records have no photo URL. Check photolink in the CSV: whitespace-only values show the fallback. A photo host may also be unavailable or blocked. The map will keep the attributes visible and show “Tree photo unavailable.” for an image-load error. Check your connection to the URL’s host; you do not need to change the tree coordinates.
